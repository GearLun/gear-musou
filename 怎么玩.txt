《齿轮无双》怎么玩（正式版 v1.1）
========================================

【开始游戏】
- 手机 / 平板玩家：打开 "齿轮无双-手机版.html"（触屏专用界面）
- 电脑玩家：打开 "齿轮无双-电脑版.html"（键鼠专用界面）
- 用 Chrome / Edge / Safari 浏览器打开，点"出 征"即可开始。
  无需联网、无需安装任何东西。
- **战场变大了**：地图 3200 × 1800（面积是镜头画面的 **6.25 倍**，长宽各 ×2.5）。
  · **镜头跟随角色**：只要角色不在战场边缘，画面就始终跟着他（角色居中），
    走到边缘时镜头会停住、角色自然偏向一侧
  · **刷怪量 ×2**（铁骑 / 总大将 / Boss 数量不变，仍是压轴登场）
  · 屏幕上的 UI（血条 / 连击 / Boss 血条 / 无双提示等）始终贴在画面上，不随镜头漂移
  · **右上角是小地图**：按整张战场 3200×1800 等比缩略，一眼看清自己在地图哪个角落。
    白点 = 你（带朝向短线）· 彩色点 = 友方召唤物（机枪/火箭炮/医疗小队/支援部队车/假人/小跟班）
    · 紫点 = 影分身分身 · 橙点 = 猫咪/猛虎；淡框 = 当前画面覆盖的范围
  · **敌人也会标在小地图上**：红点 = 普通敌人（兵卒/轻骑贼/弓兵/妖法师/铁骑/战将），
    金色大点（带光晕）= Boss 单位（总大将 / 世界吞噬者 / 世纪之花）——被围住时看小地图就知道往哪突围
  · 地狱奇遇「🔥 炽热擂台！」触发时，小地图**整个外圈会变成橙色火海带**（对应战场四周 300px 火海），
    中间绿框以内就是安全区——照着绿框走就不会被烧
  · 拿到「影分身十字斩」后，小地图上会**多框出它的生效范围**（地图正中心那块 1280×720 幕布）：
    实线紫框 = 分身正在生效；虚线紫框 = 你已离开幕布、分身失效（走出框就消失，走回来立刻恢复）
  · **鼠标只有一个准星**：战斗时系统光标会自动隐藏，屏幕上只有游戏自绘的十字准星
    （画在指针真实位置、也就是自动攻击的方向）；指针移出画面、暂停、选面板、死亡时自动恢复系统光标
  · 猛虎（哈根）驻守**整张大地图的正中心**（小地图上的橙点就是它）。
    **每 3 秒哈气一次**（屏幕中央炸出「哈！！！」），对**全场敌人**造成**按最大生命的百分比伤害**：
    **兵卒 / 轻骑贼 / 妖法师 / 弓兵 = 50% · 战将 / 铁骑 = 20% · Boss 单位 = 3%**，
    并让全场敌人**震慑 0.5 秒**——所以拿了哈根之后，杂兵基本是一波一波地被"哈"掉。
  · 影分身则镜像在**大地图正中心的对称点**上——分身只在那块「中央幕布」
    （地图中央、与屏幕等大的 1280×720 区域**再放大 1.3 倍 = 1664×936**）里存在：本体在这块幕布内，
    分身必定与本体同屏、看得见也打得到；**本体一旦走出这块范围，分身立即消失**
    （不再有飘在视野外打空气的怪相）。
    HUD 的质变栏里会标注 `影分身×N(离中央·失效)`，小地图上的紫框也会变成虚线
- 📣 **职业介绍（游戏里各处的「一句话人设」，全部出自同一张表 `CLASS_INTRO`）**：
  战士「常规战士，挥砍击杀敌人！」· 浪客「通过闪避击败敌人的潇洒浪人！」· 骑士「通过冲撞碾碎一切！」·
  武器大师「什么都会一点点！」· 弓箭手「火力覆盖！」· 士兵「大人，时代变了！」· 牌皇「幸运女神在微笑。」·
  火法师「其实我是FFF团。。。」· 雷法师「超电磁炮？我好像不会啊。」· 光法师「我才是你要找的超电磁炮！」·
  水法师「潮汐啊，我已归来！」
  （主页角色卡的小字、战士之道 / 武器选择 / 魔法转职 的卡片首行、暂停面板的职业行都用这一句；
    卡片首行加粗，下面的机制说明照旧保留）
  · **主页只显示这一句人设**：以前角色卡下面那条「专属质变：… · 专属奇物：…」的清单**已经取消**，
    想看自己这个职业能拿到哪些专属质变/奇物，请进 **📖 图鉴** 查
- 主页可先选择角色（开新局生效，并随存档保存）：
  · ⚔️ 战士：常规战士，挥砍击杀敌人！ —— 传统打法
    （**挥砍已经打不掉敌方的箭了**：想清弹幕只能按无双；无双光环仍会把附近敌人吸过来）
    （专属质变：影分身十字斩——以**大地图正中心**为镜像生成分身，与本体一同普通攻击，
      分身伤害 = 本体 20%/层，满 5 层 = 100%；**生效范围 = 地图中央那块幕布 ×1.3（1664×936）**，
      出范围即消失）
    · 🌙 **战士开局分支「浪客」**（**开局出征后、第一个奇物之前先选战法：战士 / 浪客 / 骑士 / 武器大师**）：
      · **立绘 = 持太刀的武士**（本版新做）：深蓝**着物** + 白交领 + **羽织**（胸前月纹家纹）+ 宽大的**袴** +
        白色腰带 + 宽袖随走动摆动 + **丁髷发髻**（带系发绳）、左腰挂着**空刀鞘**，
        **右手握着一把略带弧度的太刀**（鐔 + 菱形柄卷 + 刃口冷光）——
        闪避/无双时太刀前压、刃口发亮（原有的头顶「月」标记与寒气光环照旧）
      · **不会普通攻击**——输出全部来自闪避
      · **闪避 = 选定落点的一闪**：**电脑端点哪闪哪**（和法师传送一样，指针位置即落点，越界夹在场地内）；
        **手机端**用**右手闪避摇杆拖出方向**（松手朝该方向 **675px** = 战士初始闪避距离的 3 倍），
        拖动时脚下有**落点指示器**（虚线轨迹 + 落点十字圈 + 圆弧斩范围预览），所见即落点
      · **一闪是"冲过去"而不是"瞬移"**：按**距离**决定冲刺时长——基准 **675px = 0.2 秒**
        （冲刺速度 ≈3375px/s），贴脸短闪按比例更快（最短 0.05 秒），远距离最多也就 0.2 秒；
        位移全程带残影环 + 紫色碎屑拖尾，**到位后还要蓄势 0.1 秒**（约 6 帧）才挥出圆弧斩
        ——看到它落地别急着贴上去；整段动画（冲刺 + 蓄势）都是无敌帧
      · **闪避间隔基础 1 秒**；拿到质变「瞬步」后**每层 −0.1 秒，满 5 层 = 0.5 秒**
      · **自带满级瞬身**：一闪的路径上斩击敌人
      · **闪避落点挥出一刀圆形圆弧斩**：对**以落点为圆心的整圈敌人**造成伤害
        （基础半径 **150px**，升级「广域」每层 **+18%**，商店范围加成同样放大它）
      · **自动获得奇物《无双秘籍》**（无双化为「秘奥义·斩」）
      · 升级池里**没有「疾风」攻速词条**；质变**禁选 追加斩 / 剑气斩 / 旋风斩**（都挂在普攻上，浪客用不上）
      · 拿到**影分身十字斩**后：分身**同步闪避**——路径斩击 + 落点圆弧斩都一起打
        （分身伤害 = 本体 20%/层）
      · **浪客专属质变**（只有浪客能抽到）：
        · 🗡 **祖传宝刀**（新）：每 **5 秒**天降一把宝刀（落点先亮**金色预警圈**），
          砸下时对 **130px 范围**内的敌人造成 **30 + 等级×2** 点伤害（**每多一层再 +20**）；
          宝刀**插在地上留 10 秒**，浪客**走过去捡起**后**武器变成金色**、
          造成的伤害 **×2**（**每多一层 +0.75，满 5 层 = ×5**），持续 **5 秒**
        · 🔥 **烈焰步**：一闪的路径上**留下一道火墙**，贴上的敌人持续**灼伤**；
          **+1 秒/层，满 5 层 = 火墙存在 5 秒**
        · ❄️ **寒气蓄力**：**2 秒不闪避**即蓄满寒气（月牙转霜白 + 脚下霜环），
          下一次圆弧斩伤害再提高 **+0.8 倍/层（满 5 层 = 5 倍）**，
          **并且只有蓄满寒气时圆弧斩半径才 +0.24 倍/层**（满 5 层 = 额外 1.2 倍范围，150 → 330px；
          没蓄满就没有范围加成），刀光同时变成带霜特效（霜环 + 六道冰晶尖刺 + 中心霜星迸散 + 冷雾），
          **蓄满的这一刀还会把圆弧斩范围内的敌方射弹一并斩灭**（圈外的弹幕不受影响；
          没蓄满的普通圆弧斩不会清弹幕），挥刀后蓄力消耗、重新计时
        · 例：寒气 + 祖传宝刀都满级时，一刀圆弧斩 = **1.1 × 5 × 5 = 27.5 倍基础伤害**（爆发上限很高）
    · 🛡️ **战士开局分支「骑士」**：
      · **立绘 = 板甲枪骑兵**：全身钢甲 + 蓝色战袍 + **金色胸饰**、**全罩头盔**（面甲缝 + 盔缨）、
        左手**鸢盾**（金边 + 十字 + 中心宝珠，**正面闪光表示刚挡下攻击**），右手**长枪**前指
      · **没有普通攻击**：**朝鼠标指针方向持续冲锋**（手机端按**摇杆/移动方向**冲），
        **撞到的敌人吃撞击伤害**（= 你的普攻伤害 × **骑士初始攻击 ×2** × 移速加成系数）
      · **冲撞 Boss 额外伤害**：撞到 **Boss 级敌人**时，**这一击额外造成它最大生命的 5%**
        （总大将 / 魔君 / 世界吞噬者 / 世纪之花 / 双子魔眼都算；
        **只有「冲撞」才算**——旋枪、旋转长枪的圈伤、天降长矛、长枪横扫、骑兵冲撞都不带这个 5%）
      · **撞停铁骑（被动）**：和**铁骑**对撞时**打断它的冲刺**，让它**瘫痪 5 秒**
        （铁骑本来是「完全免疫控制」的，这是唯一能治它的手段：
        瘫痪期间**原地不动、不再冲锋**，并且**受到的伤害 +50%**——骑士被撞开也没关系，
        它身上会亮金色碎裂环 + 一条剩余瘫痪时间条，趁这 5 秒猛输出）
      · **撞击伤害吃移速**：**每 +2% 移动速度 → 撞击伤害 +1%**
        （例：+40% 移速 = ×1.2 伤害；+150% = ×1.75）
      · **正面挡下攻击**：举盾挡掉来自**正前方**（朝向 ±72° 内）的伤害，**背后照常掉血**；
        地狱火海/火坑这类**穿盾伤害不吃格挡**
      · **初始移速只有其它职业的 80%**；当**移速加成超过 150%** 时**骑上战马**（**纯动画**，表示加成已达标）
      · **闪避 = 旋枪**：原地转枪一圈，对身周 **165px** 内的敌人造成撞击伤害，**不产生位移**，
        **冷却固定 1 秒**（每秒最多一次）。（**拿到质变「旋转长枪」后改为「丢枪选落点」**，见下面的专属质变）
      · **无双 = 旋枪突进**：长枪持续旋转横扫，判定半径拉大到 **185px**，并且**无双期间移速 +50%**；
        **开启的那一瞬间额外从天而降 5 根长矛**砸向敌人（落点先亮预警圈、砸完**留下长矛可回收**，
        就是「天降长矛」质变那一套；场上没敌人时不会空放）
      · **升级池**：**没有攻速与范围词条**，伤害词条叫「枪锋」；移速词条叫「冲锋」，
        **每局最多 10 次、每次 +10%**
      · **质变禁选**：追加斩 / 剑气斩 / 旋风斩 / 影分身十字斩 / 瞬身 / 瞬步
      · **奇物禁选**：**无双秘籍 / 哈姆杀所有**（骑士无双是旋枪突进，这两件改写的是别的无双；
        奇物池、商店、开局三选一里都不会出现，别指望选到）
    · 🗡️ **战士开局分支「武器大师」**：
      · **升级系统完全不同**：升级时**不会**弹词条三选一，而是打开**武器大师商店 + 背包**
      · **商店（和背包同屏）**：**三栏横向排布**——左边 🛒 货架、中间 ⚔ 装备中、右边 🎒 背包（一屏看完，不用拖）
        · 每升 **1 级**送 **1 次免费三选一**（挑货架上一把武器，**白拿**）；
          **每次升级进商店，货架都会自动免费刷新一次**（这一下不算钱）
        · 免费次数用完后还想拿别的武器 → **花金币买**，**价格看品质**
          （劣等 **100** · 凡品 **300** · 优质 **1000** · 史诗 **3000** · 传奇 **5000** · 神级 **10000**）
        · **花 200 金币刷新货架**：换出一批新武器（**固定 200，不涨价**；不影响背包和当前装备）；
          **同一家店里每刷一次，下次刷新价就翻一倍**（100 → 200 → 400 → 800 …，金币不够会被拦下），
          **每次重新进店回到 100**
        · 💰 **不要的武器可以卖**：背包里每件右边都有个**「卖」**按钮，
          **卖价 = 买价的一半**，且**星级越高越值钱**（★2 翻倍、★3 再翻倍）——
          例：劣等 ★1 卖 **50** / ★2 **100** / ★3 **200**，神级 ★3 能卖 **20000**；
          **装备中的武器不能直接卖**（先点它卸下、放回背包再卖）
        · **选完武器商店不会自动关**——想继续买 / 卖 / 换装备就慢慢挑，**点「收工」才关闭**；
          没用完的免费次数会留着，下次升级接着用
      · **每把武器都有自己的模型，一眼能认出来**：木棍（带节疤的木棒）/ 弹弓（Y 形叉 + 皮筋 + 皮兜 + 石子）/
        木槌（木柄 + 铁箍桶形槌头）/ 玩具飞机（后掠翼 + 尾翼 + 转动的螺旋桨）/ 手枪（套筒 + 握把 + 扳机护圈）/ 铁剑（剑身 + 护手 + 剑首）
      · **四角武装**：**已装备的武器分别摆在 左上 / 左下 / 右上 / 右下**（最多 4 把，正好等于装备上限），
        每一把**都跟着鼠标（指针）的方向转**——电脑端朝指针，手机端朝自动锁定的最近敌人；
        武器背后那一圈淡色底光就是它的**品质颜色**
      · **出手动作按武器类型分**：**近战武器（木棍 / 铁剑 / 木槌）**出手时模型**向前挥动**（木棍还会拖出戳刺弧线、
        铁剑带刀光）；**远程武器（弹弓 / 手枪）**改成**枪身后坐**，**射弹从这把武器自己的模型口飞出去**——
        而且**固定打向鼠标指针**：枪口 → 指针 连成一条线，**指哪打哪**（不再和身体朝向平行、不会再偏出去）；
        手机端没有指针时 = 精准打向自动锁定的那个最近敌人；
        **一把近战都没装时，画面上不会有任何挥砍动作**
      · **背包**：**已装备的武器不占背包格**，背包只存「备用武器」（基础 **4 格**）；
        背包里的武器**挂在腰间**（最多看得见 3 把）；
        **点选规则（本版修正）**：**点中间 ⚔ 装备栏里的武器 = 卸下**（回到右边 🎒 背包）、
        **点右边 🎒 背包里的武器 = 装备**（装备位满了会提示）——不会再出现「想卸下却装上别的武器」的错位问题；
        **背包 + 装备位都满时再买/拿新武器 → 直接提示「背包已满！」**（不扣钱、不下架、**绝不会**动你已有的武器）；
        想腾地方就**卖掉 / 卸下一件**，或者**凑齐 3 件同名同星当场合成**（合成不占新格，满包也能买）
      · **普攻完全按「装备的每把武器」各自的数值走**（伤害 / 攻击间隔 / 攻击距离 / 判定扇角）——
        有多少把装备着就一起打；**匕首 / 小苦无 / 水波护符 / 护盾打造器 / 无人机不占普攻**：
        前两件靠**闪避**出手，后三件自己按周期或自己索敌干活 · **初始武器**：
        · 🪵 **木棍** —— **伤害 10**、**攻击间隔 0.5 秒**、对**正前方短距离戳刺**
          （介绍：*一根平平无奇的木棍*）
      · **品质**（决定稀有度、刷新概率与**买价**，共 6 档）：
        **劣等(白) 100** / **凡品(绿) 300** / **优质(蓝) 1000** / **史诗(紫) 3000** / **传奇(橙) 5000** / **神级(红) 10000**
