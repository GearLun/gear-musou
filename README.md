# 齿轮无双 (GEAR MUSOU)

纯 Canvas 2D 的无双割草风小游戏，单文件 JS，零外部资源、零依赖，离线可玩。

## 怎么玩

**方式一（推荐）**：本地服务器已在后台运行 → 浏览器打开 http://127.0.0.1:8123/
**方式二**：双击 `齿轮无双.html`（单文件版）用浏览器打开（无需服务器，音频正常）

主页除了「出 征」还有 **📖 图鉴按钮**：可随时查看全部质变与奇物的效果说明。
